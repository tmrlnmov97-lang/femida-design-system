# Femida — Design Kit

Дизайн-система юридического ИИ-сервиса Femida (femid.ai) одним комплектом:
цветовые токены в тёмной и светлой темах, типографика, шкалы отступов и радиусов,
компоненты с состояниями.

Имена совпадают с Figma и с кодом продукта: переменная `fd-bg` в Figma — это `--fd-bg` в CSS.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Живой кит: токены, типографика, компоненты в обеих темах |
| `tokens.css` | Только переменные и классы типографики, без примеров |

## Как скормить Claude Design

Дай ссылку на сырой файл и одну строку задания:

```
Дизайн-система: https://raw.githubusercontent.com/tmrlnmov97-lang/femida-design-system/main/tokens.css
Используй только эти переменные --fd-*. Своих цветов, отступов и радиусов не добавляй.
Тёмная тема основная, светлая — тот же макет с классом fd-light на корне.
```

Если нужен не только набор переменных, а и образцы компонентов, дай ссылку на `index.html`
или на страницу: https://tmrlnmov97-lang.github.io/femida-design-system/

## Правила

**Делать.** Цвета только из токенов. Заголовки serif, интерфейс sans. Тёмная тема по умолчанию.
Видимая рамка фокуса цветом `--fd-focus`. Скелетоны вместо спиннеров. Для каждого экрана —
пустое, загрузочное и ошибочное состояние. Контраст WCAG 2.1 AA в обеих темах.

**Не делать.** Произвольные hex мимо токенов. Градиенты и неоновые свечения. Текст мельче 15px.
Латинскую рыбу вместо армянского. Выдуманные цифры о базе законов. Эмодзи вместо иконок.

## Шрифты

В коде и в вебе — Noto Sans Armenian для интерфейса и Noto Serif Armenian для заголовков,
оба из Google Fonts. В каталоге Figma этих семейств нет, поэтому в макетах стоят подменные
Noto Sans и Noto Serif: перед передачей в разработку семейство в стилях `fd/*` нужно заменить.

## Размеры экранов

Десктоп 1440 основной, планшет 1024, телефон 390. Армянский текст примерно на четверть длиннее
английского — проверяйте кнопки и пункты меню на переполнение.
