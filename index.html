Femida Design Kit

Дизайн-система Femida одним файлом: 16 цветовых токенов в двух темах, 14 текстовых стилей, шкалы отступов и радиусов, компоненты с состояниями. Значения совпадают с файлом Figma «Femida / Foundations» и с переменными в коде: fd-bg в Figma равно --fd-bg в CSS.

Как скормить это Claude Design

  1. Приложи этот файл к первому сообщению. Он самодостаточный: шрифты подключаются из Google Fonts, зависимостей нет.
  2. Напиши прямо: «Используй дизайн-систему из приложенного файла. Все цвета, шрифты, отступы и радиусы бери только из переменных --fd-*. Своих значений не добавляй.»
  3. Если файл приложить нельзя — скопируй блок кода ниже в начало запроса. Это та же система без примеров.
  4. Проси обе темы. Тёмная основная: класс fd-dark на корне, светлая — fd-light.

Шрифты Noto Sans Armenian и Noto Serif Armenian есть в Google Fonts, поэтому в вебе армянский текст наберётся нормально. В каталоге Figma этих семейств нет — там в стилях стоят подменные Noto Sans и Noto Serif, и перед передачей в разработку семейство нужно заменить.

Компоненты

Соответствие PrimeVue: кнопка — Button, поле — InputText, чип режима — ToggleButton или Chip, тег — Tag, панель — Card, предупреждение — Message, загрузка — Skeleton. Для каждого интерактивного элемента нужны состояния: обычное, наведение, фокус рамкой, отключённое, загрузка.

Правила для генерации

Делать

  • Цвета, отступы и радиусы — только из переменных --fd-*
  • Заголовки serif, интерфейс sans
  • Тёмная тема по умолчанию, светлая той же разметкой
  • Видимая рамка фокуса цветом --fd-focus
  • Скелетоны вместо крутящихся спиннеров
  • Пустое, загрузочное и ошибочное состояние для каждого экрана
  • Контраст по WCAG 2.1 AA в обеих темах

Не делать

  • Произвольные hex-значения мимо токенов
  • Градиенты, неоновые свечения, «AI-эстетика»
  • Текст мельче 15px в основном потоке
  • Латинскую рыбу там, где должен быть армянский
  • Выдуманные цифры о базе законов и клиентах
  • Эмодзи вместо иконок
  • Светлую тему по умолчанию

Размеры экранов

  • Десктоп 1440 — основной
  • Планшет 1024
  • Телефон 390 — обязательны вход, чат и сайт
  • Армянский текст длиннее английского примерно на четверть: проверяйте кнопки и меню
